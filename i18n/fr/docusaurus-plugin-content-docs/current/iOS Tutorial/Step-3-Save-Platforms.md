Enregistrer une plateforme vous permet d'envoyer des messages depuis votre propre compte. Il faut une connexion Internet pour enregistrer une plateforme : faites-le avant une coupure.

RelaySMS sur iOS prend actuellement en charge 4 plateformes :

- Bluesky
- Gmail
- Mastodon
- Telegram

> Vous n'avez rien à enregistrer pour envoyer un e-mail avec **R-Mail**. Consultez [Envoyer un message](Step-5-Sending-a-Message).

### Enregistrer un compte {#save-an-account}

1. Allez dans l'onglet **Plateformes** et appuyez sur la plateforme à enregistrer.
2. Appuyez sur **Ajouter**.
3. Si iOS demande d'autoriser RelaySMS à se connecter, appuyez sur **Continuer**.
4. Connectez-vous à votre compte et autorisez l'accès. Pour **Telegram**, saisissez votre numéro de téléphone et le code envoyé dans votre application Telegram.
5. Votre compte apparaît dans la liste.

Répétez l'opération pour chaque plateforme que vous voulez utiliser. Le nombre à côté de chaque plateforme indique combien de comptes vous avez enregistrés.

<img src="/ios-mockup/platforms-saved.png" alt="Plateformes avec comptes enregistrés" class="resized-image"/>

### Supprimer un compte {#remove-an-account}

1. Allez dans l'onglet **Plateformes** et appuyez sur la plateforme.
2. Appuyez sur l'icône de corbeille rouge à côté du compte.

> *Pensez à [faire une sauvegarde](Step-4-Back-Up-and-Restore#back-up) après avoir enregistré ou supprimé une plateforme.*
