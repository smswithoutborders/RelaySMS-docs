Lorsque vous ouvrez RelaySMS pour la première fois, une courte présentation vous guide pour comprendre son fonctionnement.

>*Si vous avez une sauvegarde, pensez à la restaurer avant de poursuivre la prise en main. C'est la seule occasion de restaurer une sauvegarde. Appuyez sur le bouton Restaurer pour continuer. Consultez [Restaurer une sauvegarde](Step-4-Back-Up-and-Restore#restore) pour en savoir plus.*
