### Façons d'envoyer {#ways-to-send}

RelaySMS fonctionne de deux façons. Vous pouvez utiliser l'une ou les deux selon votre situation.

#### Méthode 1 - Envoyer rapidement avec RelaySMS Mail hors ligne (aucune configuration) {#way-1}

Idéal lorsque vous êtes pris dans une coupure et devez envoyer un message rapidement.

1. Appuyez sur Écrire sur l'écran d'accueil.
2. Sélectionnez l'option **« Envoyer depuis un alias aléatoire »**.
3. Saisissez l'adresse e-mail du destinataire et votre message.
4. Appuyez sur Envoyer.
5. Si on vous le demande, choisissez un numéro de routage dans la liste et fermez la fenêtre.

#### Méthode 2 - Envoyer avec des plateformes enregistrées {#way-2}

Idéal lorsque vous voulez envoyer depuis votre propre compte Gmail, Bluesky, Telegram ou RelaySMS Mail enregistré.

1. Appuyez sur Écrire sur l'écran d'accueil.
2. Sélectionnez votre plateforme.
3. Saisissez votre message.
4. Appuyez sur Envoyer en haut.
5. Si on vous le demande, choisissez un numéro de routage dans la fenêtre.

> *Astuce : cochez « Ne plus demander » si vous voulez réutiliser automatiquement le même numéro de routage.*

Si RelaySMS n'est pas votre application de messagerie par défaut, on vous demandera d'en choisir une pour terminer l'envoi.

### Envoyer une image {#sending-an-image}

Vous ne pouvez envoyer des images que si RelaySMS est votre application de messagerie par défaut.

1. Appuyez sur Écrire.
2. Choisissez votre plateforme.
3. Appuyez sur l'icône de pièce jointe.
4. Sélectionnez votre image.
5. Utilisez les outils de compression et de redimensionnement pour réduire le coût en SMS et accélérer l'envoi.
6. Appuyez sur Terminé.
7. Appuyez sur Envoyer.
8. Choisissez votre numéro de routage.
