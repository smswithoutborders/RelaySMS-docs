RelaySMS prend actuellement en charge 5 plateformes :

- Gmail
- Bluesky
- Telegram
- RelaySMS Mail (votre adresse e-mail RelaySMS personnelle)
- Mastodon

#### Allez dans l'onglet Plateformes et appuyez sur la plateforme que vous souhaitez enregistrer.

Une plateforme enregistrée s'allume. Appuyez dessus pour voir quel compte est connecté.

<img src="/mockup/no-platform.png" alt="Écran des comptes enregistrés" class="resized-image"/>
<img src="/mockup/accounts-saved.png" alt="Écran des comptes enregistrés" class="resized-image"/>


### Gmail

1. Appuyez sur Gmail.
2. Choisissez votre compte Gmail.
3. Accordez les autorisations.
4. Appuyez sur Continuer.

<img src="/mockup/gmail-accounts.png" alt="Compte Gmail" class="resized-image"/>

### Bluesky

1. Appuyez sur Bluesky.
2. Connectez-vous à votre compte Bluesky.
3. Appuyez sur Autoriser.

<img src="/mockup/bluesky-accounts.png" alt="Compte Bluesky" class="resized-image"/>

### Telegram

1. Appuyez sur Telegram.
2. Saisissez votre numéro de téléphone.
3. Saisissez le code envoyé sur votre compte Telegram.
4. Appuyez sur Valider.

<img src="/mockup/telegram-accounts.png" alt="Compte Telegram" class="resized-image"/>
<img src="/mockup/enter-telgram-number.png" alt="Saisie du numéro Telegram" class="resized-image"/>
<img src="/mockup/verify-telegram-code.png" alt="Vérification du code Telegram" class="resized-image"/>


### RelaySMS Mail {#relaysms-mail}

1. Appuyez sur RelaySMS Mail.
2. Choisissez de recevoir votre code via Signal ou Telegram.
3. Appuyez sur Demander le code.
4. Saisissez le code.
5. C'est fait. Votre numéro est authentifié.

<img src="/mockup/rmail-accounts.png" alt="Compte RelaySMS Mail" class="resized-image"/>
<img src="/mockup/platform-select.png" alt="Plateforme de réception du code" class="resized-image"/>
<img src="/mockup/rmail-phone-input.png" alt="Écran de saisie du numéro de téléphone" class="resized-image"/>

<h1></h1>

> **Anonyme ou authentifié** Par défaut, RelaySMS Mail vous donne un compte anonyme avec un alias aléatoire. Vous pouvez l'utiliser pour envoyer rapidement des messages sans vérifier votre numéro de téléphone. Si vous enregistrez et authentifiez votre compte, vous pouvez recevoir des réponses par SMS, même pendant une coupure d'Internet. Un compte authentifié est aussi plus sûr.

3. Appuyez sur Autoriser.
