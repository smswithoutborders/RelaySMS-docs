Actualmente RelaySMS admite 5 plataformas:

- Gmail
- Bluesky
- Telegram
- RelaySMS Mail (tu dirección de correo personal de RelaySMS)
- Mastodon

#### Ve a la pestaña Plataformas y toca la plataforma que quieras guardar.

Cuando una plataforma está guardada, se ilumina. Tócala para ver qué cuenta está conectada.

### Gmail

1. Toca Gmail.
2. Elige tu cuenta de Gmail.
3. Concede los permisos.
4. Toca Continuar.

### RelaySMS Mail {#relaysms-mail}

1. Toca RelaySMS Mail.
2. Elige si quieres recibir tu código por Signal o por Telegram.
3. Toca Solicitar código.
4. Introduce el código.
5. Listo. Tu número está autenticado.

<img src="/mockup/rmail-accounts.png" alt="Cuenta de RelaySMS Mail" class="resized-image"/>
<img src="/mockup/platform-select.png" alt="Plataforma para recibir el código" class="resized-image"/>
<img src="/mockup/rmail-phone-input.png" alt="Pantalla para introducir el número de teléfono" class="resized-image"/>

<h1></h1>

> **Anónima o autenticada** De forma predeterminada, RelaySMS Mail te da una cuenta anónima con un alias aleatorio. Puedes usarla para enviar mensajes rápidamente sin verificar tu número de teléfono. Si guardas y autenticas tu cuenta, puedes recibir respuestas por SMS, incluso durante un corte de internet. Una cuenta autenticada también es más segura.
