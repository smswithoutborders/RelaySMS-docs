La primera vez que abras RelaySMS, una breve introducción te guiará para que entiendas cómo funciona.

>*Si tienes una copia de seguridad anterior, recuerda restaurarla antes de continuar. Es la única oportunidad para restaurar una copia de seguridad. Toca el botón Restaurar para continuar. Consulta [Restaurar una copia de seguridad](Step-4-Back-Up-and-Restore#restore) para más información.*
