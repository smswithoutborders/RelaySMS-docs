# شروع کار با RelaySMS - اندروید

### حتی وقتی اینترنت قطع است، در ارتباط بمانید

RelaySMS به شما امکان می‌دهد فقط با پیامک، پیام، ایمیل و پست به پلتفرم‌های آنلاین خود بفرستید. به اینترنت نیازی نیست. مخاطبان شما پیام‌هایتان را درست مثل همیشه به‌صورت آنلاین دریافت می‌کنند.

## مراحل آموزش اندروید

از نوار کناری آموزش اندروید استفاده کنید تا مرحله به مرحله پیش بروید:

1. دانلود برنامه
2. آشنایی اولیه
3. ذخیره پلتفرم‌ها
4. پشتیبان‌گیری و بازیابی
5. ارسال پیام
6. شماره‌های مسیریابی

اگر عجله دارید، از [ارسال پیام](./Step-5-Sending-a-Message) شروع کنید و **RelaySMS Mail آفلاین** را انتخاب کنید.

## راهنمای سریع

| می‌خواهم... | چه کار کنم |
| --- | --- |
| بدون هیچ تنظیمی سریع پیام بفرستم | RelaySMS Mail آفلاین ← نوشتن ← ارسال از نام مستعار تصادفی ← ارسال |
| هنگام قطعی از Gmail خودم بفرستم | ابتدا Gmail را ذخیره کنید ← نوشتن ← Gmail ← ارسال |
| تصویر بفرستم | RelaySMS را برنامه پیش‌فرض کنید ← نوشتن ← نماد پیوست |
| از پلتفرم‌هایم پشتیبان بگیرم | منوی سه‌نقطه ← پشتیبان‌گیری ← اکنون پشتیبان بگیر ← کلید را نگه دارید |
| پلتفرم‌هایم را بازیابی کنم | صفحه خوش‌آمد (آشنایی اولیه) ← بازیابی ← انتخاب فایل ← وارد کردن کلید |

RelaySMS یک برنامه متن‌باز از پروژه SMSWithoutBorders است که برای افرادی ساخته شده که باید هنگام قطع اینترنت در ارتباط بمانند.
