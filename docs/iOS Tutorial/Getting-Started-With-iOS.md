# Getting Started with RelaySMS - iOS

### Stay connected even when the internet is off

RelaySMS lets you send messages, emails, and posts to your online platforms using just SMS. No internet needed. Your contacts receive your messages online, exactly as they normally would.

RelaySMS no longer asks you to log in or register. Everything you save stays on your device.

## iOS tutorial steps

Use the iOS Tutorial sidebar to go step by step:

1. Download the app
2. Onboarding
3. Save platforms
4. Back up and restore
5. Sending a message
6. Routing numbers

If you are in a hurry, start with [Sending a message](./Step-5-Sending-a-Message) and use **R-Mail** (no account needed).

## Quick reference

| I want to... | What to do |
| --- | --- |
| Send a message fast with no setup | Compose -> "No account" option -> Send -> Choose routing number -> Send |
| Send from my Gmail during a shutdown | Save Gmail first -> Compose -> Gmail -> Send |
| Back up my platforms | ... menu -> Backups -> Continue -> Choose folder -> Save recovery key |
| Restore my platforms | Welcome screen (onboarding) -> Restore backup -> Choose file -> Enter recovery key |
| Change my routing number | Routing numbers tab -> Tap a number -> Set as default |

RelaySMS is an open source app by SMSWithoutBorders project, built for people who need to stay connected when the internet goes down.
